三角洲行动 · 地图自动下载开关（便携版）
==========================================

分享时只需要一个文件：
    三角洲地图下载开关-单文件版.bat
把它发给别人 / 丢 U 盘 / 放桌面都行，双击就能用，不需要装任何东西。


一、它是干嘛的
--------------
《三角洲行动》启动 / 进游戏时，会在后台偷偷下载你根本不玩的地图包，
还会用 P2P 把已经下好的资源上传给别人（偷跑流量）。

负责干活的是这几个进程（不同客户端版本名字略有出入）：

    TinyDL.exe / TinyDL64.exe   新版下载引擎，启动器、游戏本体、WeGame 目录里都可能有一份
    TenioDL.exe                 腾讯老的下载 / P2P 引擎
    DeltaDL.exe 之类变体         换版本时冒出来的同类引擎

本脚本不写死路径和全名，而是按「文件名开头 TinyDL / TenioDL / DeltaDL / tinyget」
去磁盘里扫，凡是叫这些名字的 exe 全部拦住；
另外 tinydl / TenioDL 这两个专用文件夹里的任何 exe 也一起拦，
防止游戏更新后把进程改个名放进原目录、漏网。

本脚本用 Windows 自带防火墙，给这些 exe 建「出站 + 入站」阻止规则。
效果：
  · 游戏照常启动、照常登录、照常联机打已下载的地图
  · 不再自动下载新地图包，也不再上传
  · 想恢复：一键删除规则，系统里不留任何痕迹

脚本会自动把游戏装在哪个盘找出来（扫磁盘、扫注册表），
几份拷贝都会拦住，换盘、重装、换电脑都不用改脚本。

运行时会先把「扫描到的游戏安装位置」和「每个下载组件的完整路径」列出来，
你能直接看到它到底拦的是哪几个文件，确认没拦错东西。


二、怎么用
----------
1) 双击「三角洲地图下载开关-单文件版.bat」，会弹 UAC 要管理员权限
   （建防火墙规则必须要，点「是」）。
2) 菜单里选：
      1  禁止自动下载地图
      2  恢复自动下载
      3  查看当前状态（含扫描到的安装位置和组件路径）
      0  退出
3) 选 1 之后再开游戏，就不会再自动下地图了。

选 1 / 选 2 / 选 3 之后界面会停住显示结果，看完按任意键回菜单再选 0 退出。

也可以命令行直接用（分享给别人做教程时方便）：
    "三角洲地图下载开关-单文件版.bat" -Mode status     查看状态
    "三角洲地图下载开关-单文件版.bat" -Mode off        禁止下载
    "三角洲地图下载开关-单文件版.bat" -Mode on         恢复下载
（off / on 需要管理员权限，不加参数就是交互菜单。）


三、什么时候要先选「2 恢复」
----------------------------
· 游戏大版本更新、新赛季、要下新地图时
  （拦截状态下启动器可能提示更新失败或卡住，先解禁、更新完，再选 1 重新拦）
· 你想玩某个还没下载的地图时
· 需要排查「进游戏黑屏 / 提示资源缺失」时——那是没下载对应地图包，不是脚本搞坏的

平时玩已下载的地图，一直保持「1 禁止」就行。


四、这个 bat 里装的是什么（安全性）
-----------------------------------
单文件版 = 一个纯文本 .bat，里面那段乱码是 base64 编码的 PowerShell 脚本原文。
双击时它会：
  1. 检查是不是管理员，不是就自己弹 UAC 重新拉起自己；
  2. 把 base64 解回 PowerShell 脚本，临时存到 %TEMP%\DF-MapDL\payload.ps1；
  3. 执行这个脚本；
  4. 执行完立刻删掉 payload.ps1。

所以它不联网、不写注册表、不在系统里装服务，也不留后台常驻。
懂行的人可以用任何 base64 解码器把那段乱码解出来，逐行检查脚本内容。


五、规则长什么样（想手动清理时用）
----------------------------------
规则名前缀都是 DF-NoMapDL-，分组名 DeltaForce-NoMapDownload，
显示名是「三角洲行动 禁止地图下载 (出站 1)」这种。

手动清：
  控制面板 → Windows Defender 防火墙 → 高级设置 → 出站规则 / 入站规则
  → 找到「三角洲行动 禁止地图下载 …」→ 删除
或者直接再跑一次本脚本选 2，脚本只删自己建的规则，不动你别的规则。


六、常见问题
------------
Q：游戏能正常玩吗？会被封号吗？
A：只是系统防火墙拦某个 exe 的外网连接，不碰游戏文件、不改内存、不注入，
   和杀毒软件拦程序的原理一样，属于系统层面限制，不是外挂行为。

Q：进去发现某张图加载不出来 / 一直黑屏？
A：那是这张图没下载。选 2 恢复下载，进一次那张图让它下完，再选 1。

Q：换电脑 / 重装系统后还要重新弄吗？
A：规则在系统里，重装系统就没了；但脚本会自动重新找组件，重跑一次选 1 即可。

Q：为什么状态里显示 3 个组件？别人说还有 TinyDL64.exe、WeGame 目录下的？
A：这台机器上实际只有 3 个 exe（2 个 TinyDL + 1 个 TenioDL），
   没有 TinyDL64.exe，也没有 E:\Delta Force\WeGame 这个目录——不同版本客户端结构不一样。
   脚本按文件名前缀扫，别人机器上那种 TinyDL64.exe、WeGame\tinydl\TinyDL.exe
   只要存在，一样会被找出来拦掉，不用你手动加。

Q：以后游戏更新把 TinyDL 换成新版、路径变了怎么办？
A：重新双击脚本选 1 即可，脚本按文件名重新扫一遍，会按新路径重建规则。

Q：提示「未能获得管理员权限」怎么办？
A：右键这个 bat →「以管理员身份运行」。公司电脑 / 学校电脑的组策略
   可能直接禁掉防火墙规则修改，那种环境只能手动操作防火墙。


七、文件夹里的东西（自己看，分享时不用带）
------------------------------------------

使用说明.txt                       ← 本说明

源码\三角洲地图下载开关.bat        ← 调试版启动器，直接跑上面那个 ps1（改代码时用）
源码\重新生成-单文件版.ps1         ← 改完 ps1 后跑它，重新打包出单文件版 bat

重新打包：右键「源码\重新生成-单文件版.ps1」→「使用 PowerShell 运行」，
它会自动读 ps1、补 UTF-8 BOM、生成新的单文件版 bat 到上一级目录。
（单文件 bat 本身是纯 ASCII，中文全在 base64 里的 ps1 中，所以不会出现乱码。）


八、原理备注（给好奇的人）
--------------------------
防火墙规则绑定的是「程序路径 + 方向 + 动作」：
  New-NetFirewallRule -Name DF-NoMapDL-OUT-1 -Direction Outbound
                     -Program "…\TinyDL.exe" -Action Block
入站那条是为了顺手把 P2P 上传也堵掉。
规则对「任何网络配置文件（域/专用/公用）」都生效，插网线、连 Wi-Fi 都一样。
